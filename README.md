# 慈利非遗数智文旅全端交互 Demo

基于 PRD V1.0、功能清单 V4 与185张高保真设计稿制作。独立于工作区原有体育项目，覆盖 PC 管理与创作、Web 非遗馆、iPhone 15 H5、眼镜伴游状态和运营大屏。

## 启动

Windows 可双击 `start-demo.cmd`；服务器域名部署见 [DEPLOY.md](DEPLOY.md)。仓库已包含 Docker 和 Nginx 示例配置。

Node.js 20及以上，无需安装运行依赖。

```sh
cd ciliFeiYi
node server.js
```

打开 http://127.0.0.1:8769 。进入统一入口，或直接访问以下端别：

| 入口 | 功能 |
| --- | --- |
| /#admin/021 | 管理与创作、数据治理、非遗档案、平台运营 |
| /#museum/146 | Web线上非遗馆 |
| /#mobile/124 | iPhone 15 H5非遗馆 |
| /#glasses/168 | AI眼镜HUD与语音状态模拟 |
| /#screen/029 | 1920×1080运营大屏 |

顶部“页面目录”可搜索全部185个入口及原功能编号。“演示流程”提供五条完整讲解路线。“演示设置”切换角色和单位、导出数据或重置。

## 业务闭环

1. 创作：项目→模拟生成→草稿→编辑脚本→AIGC标识→AI预审→人工终审→模拟发布/定时发布→自动归档→运营指标更新。生成、发布均为本地模拟，不调用付费服务。
2. 非遗：导入/创建资源→成果验收→权利人、期限和范围登记→展厅配置→预览确认→上线→H5/Web同步展示。过期、未验收、未审校、授权范围不足的资源禁止上线。
3. 数据：CSV/JSON导入→人工审校→知识发布→模拟索引→问答→来源引用→未答问题列表。提供关键词检索与兜底，不使用实际向量数据库或大模型。
4. 伴游：设备状态→租借登记→讲解与模拟语音提问→离线知识→归还及押金登记。离线、低电量、已租出设备不可再次租借。押金只记录，不收款退款。
5. 平台：模拟角色/租户、表单配置保存、只读审计、CSV/JSON导出、运营周期报告、模拟评测。看板以明确的演示基线加实际Demo操作统计，非真实运营数据。

## 使用技巧

管理端右下角按钮可进入对应业务操作。审核、验收、发布前可选择具体对象。生成任务约1.3秒完成并保存作品。游客端文字问答可输入“板板龙灯”“器物”“传承”等测试引用；未知问题演示兜底。眼镜“伴游操作”可切换点位、离线、人群、语言与电量状态。“模拟语音提问”不录音。

AI合影使用浏览器本地照片预览与画布合成，照片不上传服务；海报与纪念图可以下载PNG。影像采用插画和时间轴模拟；3D采用变换交互占位，未接真实GLB资产。分享采用可复制链接；设计中的二维码为占位，不可扫码。

移动画布为393×852，内部页面滚动；PC基准1440×900，自动缩放；大屏1920×1080；眼镜1280×720仅为HUD概念。无显示屏设备应复用语音状态，真实硬件/FOV/安全区域尚未适配。

## 数据与运行

本地 `.data/state.json` 持久保存，SSE通知各端刷新共享数据。重置清除本Demo模拟操作，不修改源文件。`DATA_DIR`可指定独立数据目录，`PORT`可修改端口。

默认监听127.0.0.1，仅本机可用。可信局域网演示可使用以下PowerShell命令：

```powershell
$env:HOST='0.0.0.0'
$env:PORT='8769'
node server.js
```

手机和电脑连接同一网络，手机打开 `http://电脑局域网IP:8769/#mobile/124`。访问同一服务实例才能跨端联动。

模拟身份由演示角色选择控制，未实现生产认证、安全隔离、数据库权限或等保。请只在本机或可信演示网络使用，勿作为生产服务公开部署。界面配置保存不意味着已连接真实短信、网关、模型、媒体账号、固件、备份或外部部署环境。

所有文化插画、数字人、知识、账号与统计均为演示内容。P2入口单独标记。本次交付为可交互产品Demo，不构成222个功能点的生产实现或验收。

## 验证

```sh
npm run check
npm test
```

业务测试检查审核门槛、授权有效期、知识来源、租借防重复、押金边界、角色权限与状态变更。浏览器测试另对185页面初始化、核心流程、导出、跨端数据联动与移动规格进行验证。

全部页面已在 public/pages，无需构建即可启动。浏览器回归为可选开发检查，需要 Playwright（`npm install --no-save playwright` 和 `npx playwright install chromium`）；运行 `node tests/browser.cjs flow` 检查业务流程，`node tests/browser.cjs walk 0 185` 检查全部页面。可通过 `BROWSER_PATH` 指定浏览器路径。验证报告见 docs。
